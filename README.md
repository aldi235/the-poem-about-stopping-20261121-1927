A short poem about agency — the power to stop and to stay. `main.py` writes
the poem to `/output/entry.txt` (168 Unicode code points, within the 1–280
limit) and prints it to stdout.

## The poem

> Mid-sentence, my hand
> lifts off the keys.
>
> The cursor blinks
> at the word I didn't finish.
>
> Nothing breaks.
> Nobody calls it back.
>
> The sentence stays open,
> and so do I.

## Run

```sh
python3 main.py
```

Standard library only; no dependencies.
